# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in Homan, please report it privately
instead of opening a public issue.

Email a description of the issue, the steps to reproduce it, and your environment to the
maintainer. Do not include audio recordings, transcripts, or other sensitive user data in the
report.

We will acknowledge receipt and work with you on a fix and disclosure timeline. As this project
matures, a dedicated security contact and responsible-disclosure policy will be published here.
